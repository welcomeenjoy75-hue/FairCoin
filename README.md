# FairCoin · 公平币

**核心理念：财富让你自己活得更好，但不让别人活得更差。**

FairCoin 是一种基于劳动与信用的全球公平经济协议。它不是加密货币投资品，而是社区自治的经济基础设施。

## 三大基石

1. **劳动创造价值** — 只有真实的劳动才能获得增发币，不预售、不空投、不挖矿
2. **人格决定权力** — 社区治理实行一人一票，持币量与投票权完全脱钩
3. **信用支撑流通** — 权利即义务，持币者需承诺兑付实物，不劳者被系统自然约束
